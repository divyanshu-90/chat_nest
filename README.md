#  Chat Nest

Chat Nest is a simple real-time chat website where users can send and receive messages instantly.

✨ Features

- Real-time messaging
- One-on-one and group chats
- User login and authentication
- Responsive design for all devices

🛠️ Tech Stack

- Frontend: react.js
- Backend: Node.js, Express
- Real-time Communication: Socket.io
- Database: MongoDB
